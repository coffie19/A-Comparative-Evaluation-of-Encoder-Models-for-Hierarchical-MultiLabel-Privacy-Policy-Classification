# A-Comparative-Evaluation-of-Encoder-Models-for-Hierarchical-MultiLabel-Privacy-Policy-Classification
This thesis compares BERT, RoBERTa, LegalBERT, PrivBERT and a TF-IDF baseline for hierarchical classification of OPP-115 privacy policies. It evaluates performance across multiple seeds and examines fine-grained errors, label imbalance, thresholds, duplication and data leakage.
